# CarBuyWise Privacy Policy

_Effective: August 12, 2026_

## 1. Information CarBuyWise processes

CarBuyWise processes vehicle-shopping preferences that a user submits, which may include:

- Maximum purchase price
- New, used, or either shopping preference
- Model year
- Body styles and powertrains
- Cargo and seating requirements
- Desired features and priorities
- ZIP code and search radius when the user requests local dealer inventory

CarBuyWise does not ask for a real name, email address, street address, Reddit password, payment-card number, bank information, Social Security number, driver's-license number, or vehicle identification number.

## 2. How information is used

Submitted preferences are used to rank vehicle models, explain recommendations, find relevant Reddit discussions, retrieve available safety evidence, and, when explicitly requested, search dealer inventory.

CarBuyWise does not sell personal information, use it for behavioral advertising, or use Reddit data to train an artificial-intelligence model.

## 3. Information sent to third parties

### NHTSA

When NHTSA evidence is enabled, CarBuyWise sends only vehicle model year, make, model, or an NHTSA vehicle identifier to `api.nhtsa.gov` to request public recall-campaign and New Car Assessment Program safety-rating information. CarBuyWise does not send the user's ZIP code, budget, Reddit username, post content, or shopping profile to NHTSA.

### Auto.dev

When a user chooses to search live inventory and the integration is enabled, CarBuyWise sends the selected ZIP code, radius, maximum price, new-or-used preference, model year, make, and model to `api.auto.dev`. This information is used to return matching dealer listings. CarBuyWise does not send the user's Reddit username, Reddit account identifier, post history, comments, or profile content to Auto.dev.

### Reddit

CarBuyWise runs on Reddit's Developer Platform. Reddit may process app activity and account information under Reddit's own privacy policy and platform terms. CarBuyWise uses Reddit's platform APIs to retrieve relevant public discussions and create its interactive post.

### FuelEconomy.gov

EPA/FuelEconomy.gov vehicle records are synchronized by the developer and bundled with the application. The deployed app does not send individual user requests or profiles to FuelEconomy.gov.

## 4. Storage and retention

CarBuyWise currently processes recommendation and inventory-search inputs for the requested response and does not intentionally create a permanent user profile from those inputs. Reddit and external service providers may maintain operational logs under their own retention practices.

Application logs may contain technical errors and service status information. CarBuyWise is designed not to log API keys, Reddit passwords, full buyer profiles, or inventory-search ZIP codes.

## 5. Security

External API keys are stored as encrypted Devvit application settings and are not included in client-side code. No internet service can guarantee absolute security, but CarBuyWise limits information sharing to what is required for each requested feature.

## 6. User choices

NHTSA and Auto.dev integrations are disabled until their domains are approved by Reddit and enabled by the app developer. A user can receive catalog-based recommendations without using live dealer inventory. Users should not place sensitive or personally identifying information in free-text vehicle preference fields.

## 7. Children

CarBuyWise is a general vehicle-research tool and is not directed to children under 13.

## 8. Changes

This policy may be updated as CarBuyWise features or data practices change. The effective date at the top of this page will identify the latest version.

## 9. Contact and deletion questions

Privacy or deletion questions may be submitted through the public [CarBuyWise Policies issue tracker](https://github.com/tomblanchard312/CarBuyWise-Policies/issues). Do not include passwords, API keys, financial account information, vehicle identification numbers, precise addresses, or other sensitive information in a public issue.

CarBuyWise is independent software and is not affiliated with or endorsed by Reddit, NHTSA, the U.S. Environmental Protection Agency, Auto.dev, vehicle manufacturers, dealers, or listing services.
